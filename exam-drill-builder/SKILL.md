# 題庫 PDF → 練習教材

## 這個 skill 做什麼

輸入一份或多份「每題都印有正確答案」的題庫 PDF，輸出三類產物：

1. `<科目>-練習題(無答案).pdf` — 答案剝除、選項分行、左側留作答橫線
2. `解答對照表.pdf` — 每列十題的網格，對答案用
3. `刷題器.html` — 單檔離線網頁，內含全部題目

## 重要：一定要先驗證再產出

解析規則是綁定版型的，不同來源的題庫 PDF 排版不同，**不要假設一次就會對**。
流程固定為「先 `--inspect`，看過報告再產檔」。

```bash
cd scripts
pip install pdfplumber --break-system-packages   # 若尚未安裝

# 步驟 1：驗證解析（不產檔）
python3 parse_bank.py --inspect /path/to/科目A.pdf /path/to/科目B.pdf
```

檢查報告裡這四項全部要乾淨：

| 欄位 | 應該是 |
|---|---|
| 解析題數 | 與 PDF 實際題數相符（自己翻到最後一頁確認） |
| 題號不連續 | 無 |
| 選項切不開 | 空，或少數幾題且抽樣看過確認可接受 |
| 答案值異常 | 無 |

抽樣那段要用眼睛看過：題幹與四個選項有沒有被切錯。

若不通過，依情況處理：
- 題號在前、答案在後的版型 → 加 `--profile numfirst`
- 選項不是四個 → `--options 3`
- 都不符 → 在 `parse_bank.py` 的 `PROFILES` 加一條新 regex，不要改動既有的

```bash
# 步驟 2：確認無誤後產出 bank.json
python3 parse_bank.py -o bank.json /path/to/科目A.pdf /path/to/科目B.pdf

# 步驟 3：產出 PDF 與刷題器
python3 make_pdf.py bank.json --outdir /mnt/user-data/outputs
python3 make_drill.py bank.json \
    -o "/mnt/user-data/outputs/刷題器.html" \
    --title "XXX 刷題器" --pace 36 --store-key drill_xxx
```

最後用 `present_files` 把產物交給使用者。

## 參數說明

**parse_bank.py**
- 科目名稱預設取自檔名，要指定就用 `--name 金融市場常識 --name 職業道德`（順序對應 PDF）
- `--profile leading`（預設）處理 `(4) 12 題幹...(1)...(2)...(3)...(4)...`
- `--profile numfirst` 處理 `12.(4) 題幹...`

**make_drill.py**
- `--pace` 是每題目標秒數，用「測驗總時間 ÷ 題數」算。例如 100 題 60 分鐘 → 36
- `--store-key` 決定瀏覽器 localStorage 的 key。**不同題庫務必給不同值**，否則兩份刷題器會互相覆蓋進度

**make_pdf.py**
- 需要 `wkhtmltopdf` 與中文字型。容器內通常已有 Noto Sans CJK TC
- reportlab 不要用來排這種中文長文件，字型嵌入會很麻煩

## 解析邏輯的關鍵防呆

`parse_bank.py` 判定「新題開始」時，除了 regex 相符，還要求**題號等於目前題數 +1**。
這條規則存在的原因：選項換行後可能長成 `(3)9 股(4)1 股`，形式上完全符合「答案+題號」的 regex，
沒有這條約束就會被誤判成新題，導致後面整批題號錯位。改 regex 時不要拿掉它。

選項切分用**順向**掃描（依序找 `(1)`、`(2)`、`(3)`、`(4)`），不要用 `rfind`。
因為選項內文常出現 `(3)(1)、(2)皆是` 這種自我指涉，反向找會切錯。

## 刷題器的功能

- 模式：依題號／隨機／未做過／錯題本／重點題
- 錯題本：答錯自動加入，答對自動移除
- 重點題：手動標記，不會因答對而消失，需自行取消
- 計時：單題即時秒數（超過 `--pace` 轉紅）、本回累計作答時間、平均秒數
  - 累計只加總實際作答時間，不是牆鐘時間，離開再回來不會灌水
- 導覽：上一題／下一題固定在畫面底部（`position:fixed`），與進度指示同列，不隨內容長度移動；節點在 `#stage` 之外，換題時不重繪。不設條件，隨時可翻；未作答翻頁不計入 seen。也可輸入題號跳轉，找不到時會說明原因（不在本輪、超出範圍、兩科同號）
- 回看已作答的題目一律唯讀，不得重答；統計只採計第一次作答
- 鍵盤：`1`–`4` 作答、`←` `→` 前後題、`Enter` 下一題、`S` 標記重點
- 進度儲存：`window.storage` → `localStorage` → 記憶體，三層 fallback；表頭會顯示實際存在哪裡
- 進度可匯出／匯入 JSON，用來跨裝置或跨瀏覽器搬移
- 可重設「未做過」紀錄（依當前選定科目），錯題本與重點題保留，供第二輪重掃題庫

進度綁定在單一瀏覽器的 origin，換電腦或換瀏覽器不會自動同步，這點要主動告知使用者。
