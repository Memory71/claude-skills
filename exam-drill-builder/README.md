# exam-drill-builder

把「每題都印有正確答案」的公開題庫 PDF，轉成三類可練習的教材。

| 產物 | 說明 |
|---|---|
| `<科目>-練習題(無答案).pdf` | 答案剝除、選項分行、左側留作答橫線 |
| `解答對照表.pdf` | 每列十題的網格 |
| `刷題器.html` | 單檔離線網頁，含全部題目 |

## 刷題器功能

- **模式**：依題號／隨機／未做過／錯題本／重點題
- **錯題本**：答錯自動加入，答對自動移除
- **重點題**：手動標記。答對不會移除，只有自己取消才會消失，用來收「矇對但心虛」的題
- **計時**：單題即時秒數（超過目標值轉紅）、本回累計作答時間、平均秒數。累計只加總實際作答時間，離開再回來不會灌水
- **鍵盤**：`1`–`4` 作答、`Enter` 下一題、`S` 標記重點
- **進度儲存**：`window.storage` → `localStorage` → 記憶體三層 fallback，表頭會顯示實際存在哪裡
- **匯出／匯入**：進度可存成 JSON，用來跨裝置或跨瀏覽器搬移
- **重設未做過紀錄**：清除作答紀錄讓全部題目回到「未做過」，可只清當前選定的科目；錯題本與重點題不受影響

進度綁定在單一瀏覽器的 origin，換電腦或換瀏覽器不會自動同步。

## 手動使用

不透過 Claude 也能直接跑：

```bash
pip install pdfplumber
cd scripts

# 1. 先驗證解析，不產檔
python3 parse_bank.py --inspect 科目A.pdf 科目B.pdf

# 2. 報告乾淨後才產出
python3 parse_bank.py -o bank.json --name 科目A --name 科目B 科目A.pdf 科目B.pdf

# 3. 產出教材
python3 make_pdf.py bank.json --outdir ./out
python3 make_drill.py bank.json -o ./out/刷題器.html \
    --title "XXX 刷題器" --pace 36 --store-key drill_xxx
```

`make_pdf.py` 需要 `wkhtmltopdf` 與中文字型（Noto Sans CJK TC 或同等）。
`--pace` 是每題目標秒數，用「測驗總時間 ÷ 題數」算。
`--store-key` 不同題庫務必給不同值，否則兩份刷題器會互相覆蓋進度。

## 為什麼一定要先 `--inspect`

解析規則是綁定版型的。目前內建兩種：

- `leading`（預設）：`(4) 12 題幹...(1)...(2)...(3)...(4)...`
- `numfirst`：`12.(4) 題幹...`

換一份排版不同的題庫，很可能要新增 regex。`--inspect` 會印出題數、題號連續性、選項切分狀況與抽樣結果，
確認過再產檔，避免默默產出一份題號錯位的題庫。

## 兩個踩過的坑

**題號連續性防呆。** 判定「新題開始」時，除了 regex 相符，還要求題號等於目前題數 +1。
因為選項換行後可能長成 `(3)9 股(4)1 股`，形式上完全符合「答案+題號」的 regex。
沒有這條約束就會被誤判成新題，導致後面整批錯位。改 regex 時不要拿掉它。

**選項要順向掃描。** 依序找 `(1)`、`(2)`、`(3)`、`(4)`，不要用 `rfind`。
選項內文常出現 `(3)(1)、(2)皆是` 這種自我指涉，反向找會切錯。
